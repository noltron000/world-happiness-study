# World Happiness Study
*You can view the project live on [**GitHub Pages**](https://projects.nebuloid.dev/world-happiness-study/)!*

This project showcases some basic functionality with JavaScript to read in csv and json data, and display it in a web page.
In particular, you will see a series of tables and graphics demonstrating the dataset.

Data Source: [World Happiness Report on Kaggle](https://www.kaggle.com/datasets/unsdsn/world-happiness/data)
